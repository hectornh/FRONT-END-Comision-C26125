# La Pequelette - Sitio Web

## ¿Qué es esto?

Este es el sitio web de **La Pequelette**, una chacra agroecológica en Cañada de Alvarez, Calamuchita, Córdoba. La hice para que los clientes puedan ver sus quesos y untables, leer sobre cómo los elaboran, y mandar un mensaje al hacer un pedido.

## Cómo llegué a hacer este sitio

Primero armé la estructura básica de la página: el encabezado con el logo y el menú, una sección de inicio con las cabras de fondo, una grilla con los productos, opiniones de clientes, y un formulario para escribirme. Todo organizado de forma ordenada para que se pueda leer y entender fácilmente.

Después le di estilo con colores, tipografías y diseño. Elegí tonos que van con lo que soy: lila del logo, marrones cálidos, fondos crema. Las fuentes las traje de Google Fonts para que se vean bien en cualquier computadora.

También hice que el sitio se adapte a cualquier pantalla.

Más adelante agregué interactividad para que al hacer clic en un producto se abra una ventana con más información, y la opción de agregarlo al carrito. El carrito recuerda lo que pusiste aunque cierres y vuelvas a abrir la página.

El formulario de contacto también valida que hayas puesto bien el nombre y el correo antes de enviarlo.

Finalmente subí todo a GitHub.

## Qué tiene el sitio

- Página de inicio con foto de la chacra
- Sección con todos mis productos y sus precios
- Información sobre cómo produzco mis quesos, con el mapa de dónde estoy
- Opiniones de clientes
- Formulario de contacto para hacer pedidos
- Carrito de compras donde podés agregar y quitar productos
- Diseño adaptado para celular, tablet y computadora
