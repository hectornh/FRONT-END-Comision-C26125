# La Pequelette - Chacra Agroecológica

Sitio web de la chacra agroecológica **La Pequelette**, productora de quesos artesanales elaborados con leche de cabra en Cañada de Alvarez, Calamuchita, Córdoba.

## Descripción

Este proyecto es la página de inicio (Home) del ecommerce de La Pequelette. Permite a los visitantes conocer los productos disponibles (quesos frescos y untables), leer reseñas de clientes y hacer consultas o pedidos a través del formulario de contacto.

## Estructura del proyecto

```
lapequelette/
├── index.html        # Página principal
├── styles.css        # Hoja de estilos
├── README.md         # Este archivo
└── img/
    ├── logo.png      # Logo de la chacra
    ├── hero.jpg      # Imagen de fondo del hero
    └── productos/    # Fotos de los productos
```

## Tecnologías utilizadas

- HTML5 con etiquetas semánticas (`header`, `nav`, `main`, `section`, `footer`)
- CSS3 con Flexbox y CSS Grid
- Google Fonts (Playfair Display + Lato)
- Formspree para el formulario de contacto
- Diseño responsivo con Media Queries

## Secciones

- **Hero**: imagen de las cabras con llamada a la acción
- **Productos**: cards con Flexbox mostrando quesos y untables
- **Nosotros**: descripción de la producción agroecológica con video
- **Reseñas**: opiniones de clientes en CSS Grid
- **Contacto**: formulario conectado a Formspree

## Zona de entrega
